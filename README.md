# YAKEKOGE - Add Burn Color MOD (v1.0.1)

A simple config mod that adds realistic atmospheric reentry burn marks/discoloration to ALL KSP parts. 
By distributing a minuscule amount of Ablator resource to every part, it triggers the stock game's burn-color shader.

## ■ Requirements (Dependencies)
- **ModuleManager** (Required)
  * Confirmed working with ModuleManager version 4.2.3.
 
##  ■ Installation
Extract the downloaded ZIP file, and copy the "YAKEKOGE_AddBurnColor" folder (located inside the GameData folder) directly into your KSP "GameData" directory.

[Correct Path Example]
Kerbal Space Program / GameData / YAKEKOGE_AddBurnColor

## ■ Important Note / Warning
Since a tiny amount of Ablator resource is added to every single part, it may slightly affect the weight/mass balance of extremely lightweight crafts or massive vessels with huge part counts. Please keep this in mind during design!

### [日本語 / Japanese]
■ 概要
すべてのKSPパーツに大気圏再突入時の焦げ目（変色エフェクト）を追加するシンプルな設定MODです。
各パーツに極小のAblator（断熱材リソース）を配ることで、ゲーム標準の焦げシェーダーを強制的に呼び出します。

■ 動作要件 (前提MOD)
- ModuleManager (必須)
  ※バージョン 4.2.3 にて動作確認済みです。

■ 導入方法
ダウンロードしたZIPファイルを解凍し、中にある「GameData」フォルダ直下の
「YAKEKOGE_AddBurnColour」フォルダを、お使いのKSPの「GameData」フォルダ直下に
丸ごと貼り付けてください。

【正しい配置の例】
Kerbal Space Program / GameData / YAKEKOGE_AddBurnColor

■ 注意点
ごく少量ですが全パーツにリソースが追加されるため、非常に軽量な機体や、
パーツ数が極めて多い巨大な機体では、重量バランスに若干の影響を及ぼす可能性があります。
